# Security policy

Cleared is an alpha that can run agent CLIs, inspect project files, post to Linear and GitHub, and merge an approved pull request. Security reports about these paths are in scope: identity and approval checks, version pinning, permissions, model adapters, the private-term guard, dashboard access, state and token files, update scripts, and installer behavior. A defect in a project that Cleared operates is outside this repository unless Cleared causes or amplifies it.

Please **report vulnerabilities privately** through this repository's **Security → Report a vulnerability** form on GitHub. Include the affected revision, exact steps or a minimal proof of concept, impact, and a safe way to reproduce. Do not put secrets, live project data, or exploit details in a public issue or pull request. Maintainers will triage the private report and coordinate a fix and disclosure with the reporter. There is no promised response time during alpha.

For setup and protection limits, read [docs/security.md](docs/security.md). For community conduct concerns, use the private contact method in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
